FAQ
Do I have to start at Module 1?
Nope. Jump in wherever matches your level. If you've been using ChatGPT for a year, start at Module 2. If you already know prompting techniques, start at Module 3. Module 1 is only for complete beginners.
How long does each module take?
Anywhere from 8–15 minutes depending on how long you spend on the exercises. They're designed to be done in one sitting — grab a coffee and go.
Is there a quiz at the end?
Each module has 3 quizzes built in throughout — not just at the end. The feedback explains why each answer is right or wrong, so you actually learn from them rather than just checking a box.
Do I need to create an account to use Claude?
You can try Claude for free at claude.ai — no credit card needed. A free account gives you access to basic conversations. Paid plans unlock longer context windows and more advanced models.

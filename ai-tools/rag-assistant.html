AI / RAG project

Learn Claude Assistant

A retrieval-augmented question box built over my 13-module Learn Claude course. Instead of guessing, it searches the actual module text for the most relevant passages, then answers using only what it finds there.

Voyage AI embeddings Claude API Vercel serverless Vanilla JS
How it works
  1. Each module is split into chunks and converted into embeddings — numeric representations of meaning — using Voyage AI.
  2. Your question gets embedded the same way, and the closest-matching chunks are found by comparing vectors.
  3. Those chunks are handed to Claude as grounding context, so the answer is based on the actual course material, not general knowledge.
Why I built this

The Learn Claude series started as a set of interactive lesson modules I built to teach AI basics — lessons, quizzes, and try-it exercises, all client-side JavaScript. This project reuses that same content as the corpus for a small RAG system: the lesson text was extracted from each module, split into topic-sized chunks, and converted into embeddings so a question can be matched to the passages that actually answer it, instead of relying on a model's general training.

A few deliberate choices shaped the build. There's no vector database — at 13 modules, a flat JSON file of embeddings and a brute-force similarity search is simpler and fast enough. The assistant will also work without any API key on your end: it falls back to returning the raw matching excerpts instead of a written answer, so the retrieval side always works, and a written answer is available if you add your own Anthropic key for that one request.

Stack: Voyage AI for embeddings, the Claude API for generation, a Vercel serverless function for retrieval and orchestration, and plain HTML/CSS/JS for the interface — no framework, to keep it consistent with the rest of this site.
